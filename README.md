# PROJECT: INDUSTRIA

**Статус:** Phase 3 — Building Foundation реализована; одиночный и двухклиентский тесты пройдены, задачи ожидают проверки владельца. PRE-016 Rojo live-sync остаётся открытой.  
**Платформа:** Roblox  
**Движок и язык:** Roblox Studio / Luau  
**Цель первой версии:** кооперативная factory automation sandbox для 4–6 игроков.

PROJECT: INDUSTRIA — игра о проектировании и расширении совместного автоматизированного завода на одной большой карте. Игроки исследуют местность, находят месторождения, строят добывающие и производственные линии и постепенно автоматизируют промышленность.

## Основные решения

- Переключаемая камера от первого и третьего лица.
- Свободное строительство с привязкой к сетке 4 studs и поворотом по 90°.
- Видимые движущиеся предметы на конвейерах при оптимизированной логической симуляции.
- Одна общая карта, сервер на 4–6 игроков.
- Средний темп и постепенное усложнение; баланс глубины и доступности.
- Стилизованная промышленная эстетика с собственной идентичностью.

Подробности: [GDD](GDD.md), [архитектура](ARCHITECTURE.md), [решения](DECISIONS.md), [план](ROADMAP.md).

## Инструменты

- Git для локального контроля версий.
- Rojo 7.7.1 для синхронизации исходников с Roblox Studio.
- Roblox Studio MCP для анализа и тестирования места.
- Blender MCP для создания и подготовки моделей.

Rojo CLI устанавливается в `%LOCALAPPDATA%\Programs\Rojo`; Studio-плагин — в пользовательскую папку Roblox Plugins. Если новая команда `rojo` не находится, откройте новый терминал, чтобы обновить `PATH`.

## Открытие проекта

1. Откройте Roblox Studio и проект INDUSTRIA.
2. В корне этой папки выполните `rojo serve default.project.json`.
3. В Roblox Studio откройте плагин Rojo и подключитесь к локальному серверу.
4. Сохраняйте или публикуйте место только после проверки изменений.

Для проверки сборки используйте `rojo build default.project.json --output build/INDUSTRIA.rbxlx`.

## Правила разработки

Работа ведётся автономно по небольшим задачам. После каждой задачи создаётся коммит с описанием изменений, проверок и ручных проверок для владельца. После фазы создаётся итоговый коммит. Задачи остаются REVIEW до принятия владельцем. Отправка в origin разрешена владельцем в текущей сессии.

## Строительство (Phase 3)

B — режим строительства, R — поворот на 90 градусов, клик — размещение, X — демонтаж объекта под указателем. Зелёное превью означает допустимое место, красное — препятствие или превышение дальности. На сессию выдаётся 20 временных строительных единиц; блок стоит одну, демонтаж возвращает её. Сохранений ещё нет. Phase 2 пропущена по решению владельца, используется стандартная камера Roblox.
