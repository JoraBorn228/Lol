# TASKS — PROJECT: INDUSTRIA

Статус REVIEW означает, что работа выполнена и ожидает проверки владельца. Ни одна задача не отмечается APPROVED без его решения. Владелец разрешил автономное выполнение задач с коммитом после каждой задачи и итоговым коммитом фазы. PRE-016 остаётся открытой до подтверждения Rojo live-sync.

## Статусы

- LOCKED — ещё не доступна.
- READY — готова к выполнению.
- IN_PROGRESS — выполняется.
- REVIEW — ожидает проверки владельца.
- APPROVED — принята владельцем.
- REJECTED — отклонена.
- BLOCKED — заблокирована зависимостью.
- SKIPPED — пропущена по прямому решению владельца.
